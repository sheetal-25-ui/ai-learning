## Rule for every video
1. Make a folder: `NN-topic-name/` (example: `05-structured-output/`)
2. Code along in `code.ipynb`
3. Copy `templates/notes-template.md` into the folder as `notes.md` and fill it in from memory
4. Add one line to `cheatsheet.md`
5. Commit and push
